Project Title->Amazon Product Reviews Sentiment Analysis Using Python

1. Project Overview
This project performs Sentiment Analysis on Amazon product reviews using Natural Language Processing (NLP) techniques.
The project classifies customer reviews into:
Positive
Negative
Neutral
The aim is to understand customer opinions and product feedback using Python.

2. Objectives
The project helps to:
Analyze customer opinions
Detect sentiment patterns
Perform text preprocessing
Visualize sentiment distribution
Build practical NLP skills

3. Technologies Used
Python
Pandas
NumPy
Matplotlib
Seaborn
NLTK
TextBlob
